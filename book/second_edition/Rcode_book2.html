Computer programs for group sequential tests

We are making available for downloading some of the R code used to construct group sequential tests and to calculate their properties.

Programs presented here perform calculations to construct and evaluate group sequential tests. They are provided as a service to readers.

The programs are presented using the notation of the book and, in particular, the method of computation for normally distributed test statistics is as described in our Chapter 31.

Code is written in R. It is self-contained and does not rely on other software packages.

To retrieve .R files

  • Click on the highlighted name. A listing will appear in the window.
  • Click on File (top left hand corner) and select the Save option to save as an R file -- in text format. The program should be ready to use.

Here are some key routines. More documentation and examples of the use of these routines will follow ...

  • standards.R group sequential tests
  • erspt.R error spending tests
  • findroot.R finds the root of an increasing function
  • dunnett.R Dunnett P-value
  • simes.R Simes P-value
